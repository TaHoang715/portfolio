# 3D Model Directory

Đặt file model 3D Arlecchino tại đây với tên:
`public/models/arlecchino.glb`

Hệ thống đã được lập trình tự động:
1. Khi có file `arlecchino.glb`, trang web sẽ tự động load và render model 3D đầy đủ cùng chuyển động xoay theo con trỏ chuột.
2. Khi chưa có file hoặc đang tải, trang web hiển thị bản thiết kế 3D Holographic Avatar & Balemoon Halo độc quyền.
